# Onboarding: 001-mvp-nucleo-operacional

1. Subir o app EngrenaCode (shell Electron + server loopback).
2. No gate `#login`, criar workspace + senha (primeiro uso) ou desbloquear.
3. Abrir `#configuracao`: conectar Claude (assinatura), testar CLIs, salvar prompt se desejar, salvar PAT GitHub válido.
4. Voltar ao `#dashboard` e confirmar saúde da config.
5. Adicionar projeto (pasta local) e criar thread (provider + access + mode).
6. Enviar mensagem, observar streaming/tools, revisar diffs (accept/reject).
7. Com thread idle, fazer commit/push/abrir PR.
8. Em `#skills` / `#rules` / `#subagents`, criar artefatos, vincular ao projeto e validar no próximo turno.
9. Confirmar que segunda execução longa no mesmo projeto retorna `thread_busy`.
